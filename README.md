## WaCadeXR is a WIP open source re-implementation of WACVR for Godot. ##

It directly supports all versions of the game that WACVR supports and runs on the same backend hooks.
By extension, this means it follows a nearly identical setup process.

<img width="1438" height="986" alt="image" src="https://github.com/user-attachments/assets/4798147b-ecac-4dd2-95e7-95ee2c03f488" />

The project is quite barebones at the moment, but fully functional and all buttons and sensors react as they would on a physical machine.

**Disclaimer:**
This project contains many resources adapted from the WACVR project for Unity which you can find here: https://github.com/xiaopeng12138/WACVR/tree/main
You should also go here for surface level setup instructions!

**On AI Use:**

While I have tried my best to wrap my head around how the backend lighting hooks work, I also wanted to get a working prototype out relatively quickly.
Additionally, I am not experienced in C# and mainly focus on GDScript.
For that reason, much of the C# code has been taken from WACVR and modified with the assistance of Gen-AI or was written by Gen-AI.
I'm going to be continuing on trying my best to understand the code that I'm writing (i am also concerned about AI turning my brain to mush :p) and hopefully we'll be able to build
an open tool to play the game we all love together!!
